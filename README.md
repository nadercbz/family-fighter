# Family Fighter

Street-Fighter-Spiel mit der Familie als Kaempfer. Zu zweit an einer Tastatur, mit Gamepad oder am Handy im Querformat gegen die CPU.

Spielen: https://nadercbz.github.io/family-fighter/

Am Handy: Seite oeffnen, Querformat, ueber das Teilen-Menue "Zum Home-Bildschirm" hinzufuegen, dann laeuft es im Vollbild.
